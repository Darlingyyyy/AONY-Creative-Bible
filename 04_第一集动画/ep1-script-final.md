## Beat -1 — 被认证的英雄（0s-10s）

**核心目的**：展示前世英雄与黑暗神55开 → 黑暗神觉醒后28开。证明英雄是世界认证的强者。

| 秒 | 画面 | 情绪 |
|----|------|------|
| 0–1 | 黑屏。心跳一声。画面亮起。远古战场中央——英雄和黑暗神正在对攻。英雄侧身闪过暗影臂，辉光斩水平横劈，黑影被切开金色裂口——裂口合拢前能看到少女轮廓一闪而过。黑暗神退了半步。 | 这个人能和黑暗神正面交锋 |
| 1–3 | 英雄光之解放展开金色光翼，黑暗神释放暗紫冲击波。两股力量对撞——金色和紫色各占一半天空。僵持两秒。同时炸开。英雄退5步，单膝点地后立刻站起。黑暗神退3步，黑影颤抖——它在消耗。 | 55开。观众应该觉得「他能赢」 |
| 3–4 | 镜头推进黑暗神胸口。少女轮廓变化——头抬起，银发飘动。她睁眼了。浅琥珀色的完整眼睛，瞳仁里倒映一片漆黑。英雄的手抖了一下。大法师远处喊：「它还没——」话没说完。 | 少女睁眼 = 它醒了 |
| 4–6 | 少女眼眶涌出暗紫光。暗紫纹路从她向外蔓延——和女主封印纹路一模一样，方向相反。黑影膨胀到近20m。光线经过都会弯曲。金色光芒被压到只有两成。 | 28开。不是新形态，是醒了 |
| 6–8 | 觉醒后黑暗神一鞭砸下。英雄举剑格挡——剑上金色光流剧烈闪烁。被压得单膝跪地，但没有倒下。他看到了少女——她在看他。浅琥珀色的眼睛直视他。英雄的眼神变成「你是谁」。第二击来了。 | 被压制但不绝望 |
| 8–9 | 英雄没有格挡——侧身冲进暗影内部。金色光翼全开，剑尖对准少女。差一米就碰到了。黑暗神第三击从侧面扫飞他。飞出十几米，砸在焦土上滑行。剑插在五米外。他趴着，手指在焦土上留下五道抓痕。 | **差一米**——核心悬念 |
| 9–10 | 英雄撑起上半身。眼神没涣散——他在算距离：到剑五米，到黑暗神二十米。他还在想怎么打。然后冲击波来了——（接 Beat 0） | 不是被打倒，是被打断 |

## Beat 0 — 冲击波（10s-16s）

**核心目的**：三人被震散，暴露女主的异常抗性。

| 秒 | 画面 |
|----|------|
| 10-11 | 暗紫色冲击波扩散。英雄再次被击飞——剑脱手插入焦土（约8米外）。大法师法杖撑地，被推开三步。 |
| 11-12 | 女主只踉跄了一步。手按胸口，眉头微皱。她没有看黑暗神——她在看黑暗神胸口那个少女轮廓。 |
| 12-14 | 大法师侧头看地上的英雄。**「站起来，愣着干嘛。」** 不是责备，是催促。 |
| 14-16 | 英雄爬起，拔剑。剑身金色光流重新亮起。三人重新站位。 |

## Beat 1 — 协同战斗（16s-26s）

**核心目的**：三人配合展示技能组合——证明他们很强，只是对手异常。

| 秒 | 画面 |
|----|------|
| 16-19 | 英雄主攻：辉光斩开路 → 盾击控场。大法师远程：冰霜新星冻结涌出的暗影小兵 → 火球术点杀 → 雷击连锁弹跳。 |
| 19-22 | 女主辅助：守护之盾给英雄 → 弱点标记挂在黑暗神身上。标记在黑影表面短暂停留——然后被吞噬。又一次「无效」暗示。 |
| 22-26 | 三人配合流畅。观众应该觉得：**如果他们打的是别的敌人，早赢了。** 然后黑暗神发出低沉的震动——地面裂谷扩大。 |

## Beat 2 — 黑暗神暴怒（26s-36s）

**核心目的**：绝境——常规手段全部失效。

| 秒 | 画面 |
|----|------|
| 26-30 | 黑暗神释放第二波能量。暗紫色触须从地面裂缝涌出——每条都有手臂粗，缠向三人。 |
| 30-33 | 英雄被触须缠住右臂，大法师被击倒。女主的守护之盾碎裂——碎片在她面前散成光点。但她还是没倒。 |
| 33-36 | 女主抬头。黑暗神低头。她们隔着黑影对视——女主看的不是三团紫火，是紫火后面的那个少女轮廓。黑影中的少女银白发丝微微飘动——第一次有动作。女主的表情变了：不是恐惧，是「我明白了」。 |

## Beat 3 — 封印（36s-56s）

**核心目的**：女主牺牲——全片情感高潮。

| 秒 | 画面 |
|----|------|
| 36-38 | 女主向前走了一步。大法师伸手想拉她——手停在半空。他什么都没说。他知道。 |
| 38-42 | 暗紫色纹路从女主胸口浮现 → 锁骨 → 颈侧 → 向左眼蔓延。和黑影中少女的纹路完全一致的路径，但方向相反——一个向外扩散，一个向内汇聚。 |
| 42-46 | 黑暗能量开始逆转——从黑暗神流入女主身体。黑影开始收缩。少女轮廓越来越清晰——她睁开了眼。不是之前浅琥珀色的完整眼睛——是空洞的眼眶。漆黑。一秒。然后重新闭上。 |
| 46-50 | 纹路从紫色烧成金色。封印阵以女主为中心展开——多层金色环形符文旋转上升。黑暗神黑影急剧缩小，像被吸进女主胸口。金色光柱冲天。 |
| 50-52 | 光柱中，女主回头。看英雄，看大法师。笑了。**「我们……会再见的。」** |
| 52-54 | 她的身影透明化。最后消失的是那双眼睛——浅琥珀色变成纯金色，然后化作一颗金色光点。光柱消散。 |
| 54-56 | 大法师伸手接住那颗光点。什么都没说。英雄闭上眼睛——不是伤势，是无法承受。光点在法师掌心跳动了两下，暗了。 |

## Beat 4 — 觉醒（56s-72s）

**核心目的**：时空跳转，建立第一章起点。

| 秒 | 画面 |
|----|------|
| 56-58 | 黑屏。持续2秒。 |
| 58-60 | 鸟鸣声先于画面。一只鸟。窗外。 |
| 60-62 | 清晨阳光从木窗缝隙照进来。光束中有缓慢浮动的尘埃。 |
| 62-64 | 18岁的主角猛然惊醒。手按胸口——和前世英雄被击中的位置一样。大口呼吸。 |
| 64-68 | 他坐在床上。窗外有风吹进来，吹动床边桌上的一本书。封面翻开——里面夹着一根深蓝色发绳。他不认识这东西，但手停在了上面。 |
| 68-72 | 起身，走向木窗，推开。神树村全景——晨雾中一棵巨树从村中心升起，树冠覆盖半个天空。阳光穿过树叶，光束中尘埃缓慢浮动。主角看着那棵树——他的表情不是「真美」，是「我好像来过这里」。 |

## 制作备注

- **黑暗神觉醒的视觉区分**：55开阶段黑影约12m、暗紫黑色、少女闭眼静止；觉醒后约20m、纯黑吞噬光线、少女睁眼活动
- **封印纹路方向**：女主是从外向内汇聚（冰裂→燃金）；少女是从内向外扩散（向外蔓延）。视觉上必须是镜像
- **金色光点**：女主牺牲后留下的光点，大法师接住。它暗了，不是消失了——暗示她还在某处
- **第1集核心钩子**：不是「黑暗神太强了怎么办」——是「那个少女是谁」「差一米是什么意思」「女主真的消失了吗」
