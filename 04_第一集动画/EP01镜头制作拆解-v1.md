# EP01《前世梦境》镜头制作拆解 v1

> 目标：把现有 80 秒脚本拆成可执行的动态分镜制作单。

## 成片定位

- 时长：80 秒
- 画幅优先级：竖屏 9:16，其次横屏 16:9
- 风格：anime cinematic / 幻想电影感 / 高情绪密度
- 制作方式：关键帧 + 镜头运动 + 字幕 + 音效 + BGM + 少量特效

## 必做关键帧

为了控制成本，先做 8 张关键帧即可覆盖全片：

1. 远古战场总览：英雄与黑暗神对峙。
2. 金紫能量对撞：英雄证明自己很强。
3. 黑暗神胸口少女睁眼。
4. 三人重新站位：英雄、诺亚、塞莉亚。
5. 塞莉亚看见黑影少女，明白命运。
6. 塞莉亚封印，紫纹燃金。
7. 光点落入诺亚掌心。
8. 艾伦醒来，桌上深蓝发绳。

## 台词

全片台词要少，越少越有重量。

1. 诺亚：“站起来，愣着干嘛。”
2. 塞莉亚：“我们……会再见的。”

可选旁白只放标题卡：

> 即使整个世界忘记了你，我也会再次找到你。

## 音效重点

- 心跳：开头黑屏，低频单声。
- 剑鸣：0-2 秒作为开画信号。
- 能量对撞：金色高频 + 暗紫低频。
- 封印：不要爆炸声，要像巨大的呼吸反向吸入。
- 光点：两次轻微心跳。
- 清晨：鸟鸣先于画面。

## 风险点

- 黑暗神少女不能做得太像恐怖鬼魂，必须悲剧、安静、空。
- 塞莉亚不能做成普通圣女牺牲，要像“早知道这一天会来”。
- 诺亚不能哭喊，最痛是他伸手停住。
- 英雄不能显得弱，他是强者，只是对手异常。
