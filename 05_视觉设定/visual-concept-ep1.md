## 一、远古战场

### 核心意象
**「一场战争刚结束，但血的温度还没散。」**

不是荒芜千年的废墟，而是刚刚被蹂躏过的战场。焦土还在冒烟，空气中飘着灰烬。地面有新鲜裂谷，从裂口渗出暗紫色光——黑暗神的力量在侵蚀大地。

### 具体造型

- **空间**：直径约80m的不规则圆形盆地。边缘被暗紫色半透明能量墙封住（不是石墙，是流动的能量屏障，碰到会泛起涟漪）。天空不是黑色的——是暗紫色和暗红色的能量风暴，像受伤的天空。
- **地面**：焦土为主，炭黑+暗褐。散落着破碎的兵器、断裂的旗杆、烧焦的残甲。多处裂谷缝隙，宽窄不一，从缝隙中透出幽暗的紫光。
- **地标遗物**：盆地中央偏后有一根倾斜的巨型石柱，表面刻满已被磨损的古代符文。战斗时偶有金色残光沿符文闪烁——暗示这是封印战争时期的遗迹。
- **氛围**：风中飘着灰烬和火星。远处隐约有金属碰撞和嘶吼的回声，但画面内无其他活人。

### 色彩方案
- 主调：炭黑60% + 暗褐20% + 暗紫10%
- 点缀：裂谷紫光(#6030a0)、灰烬橙红(#804020)、残甲冷铁灰(#505868)
- 天空：暗紫(#2a1040)为底，暗红(#401820)为云，偶有苍白闪电

### 情绪关键词
压抑·刚经历绝望·但还没输


## 二、黑暗神

### 核心意象
**「巨大的黑影中间，隐约能看到一个少女。她闭着眼，像在沉睡。」**

黑暗神不是怪物化的恶魔——是一团巨大的暗影能量，而在黑影的中心，有一个若隐若现的少女轮廓。她的姿态很安静：双脚悬空，头微微低垂，双手自然垂在身侧。她看起来不是被囚禁，更像是"成了黑暗神的心脏"。

这个少女就是黑暗神的上一任容器——一个曾经和女主一样的女孩。她已经完全被同化了，只剩一个残影。女主的命运就是她的命运。这个画面是全片最深的伏笔：**女主看到的不是敌人，是自己未来的倒影。**

### 具体造型

- **外层黑影**：高约12-15m，人形轮廓但边缘模糊、不断流动。材质像液态暗影——表面有暗紫色能量流持续向下坠落，像从少女身上剥落。
- **内层少女**：隐约可见于黑影胸腔位置。15-18岁的少女形态。银白色长发（和女主同色——不是巧合），闭眼，面容平静。身体呈半透明，像被封在水晶或琥珀里。偶有暗紫色纹路从她身上向外蔓延——那是早已完成的"同化"。
- **关键细节——眼睛**：少女全程闭眼。但在封印发动的瞬间（女主封印自己的那一刻），黑影中的少女睁开了眼——只睁开一秒。她的眼眶里什么也没有，是空的。然后再次闭眼。只有观众能注意到。
- **关键细节——手**：少女的右手微微抬起，手指自然微张——像"曾经想要抓住什么，但那个东西已经不在了"。
- **动作方式**：黑影移动时，少女的姿态不变——她是静止的，只有黑影在流动。攻击不是少女发出的，是外层暗影自主爆发。这暗示少女意识已熄灭，黑暗神只是"穿着她的躯壳"。

### 色彩方案
- 外层黑影：暗紫黑(#1a0528)，流动处(#2a1040→#401860)，边缘融入环境
- 少女轮廓：半透乳白(#e8e0d8, alpha 0.2-0.4) + 银白发丝偶尔被紫光照亮
- 同化纹路：暗紫(#6030b0)，从少女向外蔓延
- 空眼眶：纯黑(#000)，瞬间出现
- 攻击特效：紫黑+暗红，带低频震动感

### 情绪关键词
恐怖来自共情·不是怪物是悲剧·女主看到的自己的未来


## 三、前世英雄（23岁）

### 核心意象
**「一个已经战斗了很久的年轻人。铠甲碎了，体力尽了，但他还没放下剑。」**

23岁——本该是初出茅庐的年纪，但他已经在打一场没有增援的仗。他不是"身经百战的老将"，他是"被战争提前催熟的人"。他的疲惫不是年龄的疲惫，是撑太久的疲惫。

### 具体造型

- **年龄/面容**：23岁。脸上还有年轻人的棱角，但眼神已经不像23岁。干涸的血迹和灰烬黏在额角，眼眶下有阴影——不是黑眼圈，是连续战斗没睡的痕迹。眼神不迷茫——他知道自己在做什么。
- **发型**：深棕色乱发，长度到脖子，被汗和血粘在脸侧。左鬓角有一缕白发——使用神圣力量过度的痕迹（伏笔：第一章主角觉醒后同位置也会出现）。
- **铠甲**：残破的银色板甲。左肩甲已碎裂半垂，右臂护甲有多道爪痕。胸甲中央的纹章被打碎了一半——暗示他来自某支骑士团。不是"帅气的战损"，是真实的消耗。
- **武器**：单手长剑，剑格嵌暗金色宝石。剑身有微弱金色光流在纹路中游走——这是辉光斩的来源。刃口有缺口，但依然锋利。
- **站姿**：重心压低，持剑的右臂没有放下过。不是摆pose——是"随时准备再冲"。

### 色彩方案
- 铠甲：暗银(#888898) + 焦痕黑(#302828) + 磨损金边(#806830)
- 肌肤/发型：战斗灰(#c8b4a0) + 深棕发(#4a3028) + 左鬓白(#d8d0c8)
- 剑光：暖金(#d4a820→#ffe8a0)

### 情绪关键词
被提前耗尽的年轻·沉默的可靠·握剑的手从来不抖


## 四、大法师（25岁）

### 核心意象
**「他用不耐烦来掩饰恐惧。不是怕死——是怕再次失去。」**

25岁，天赋极高但过早承担了不该承担的责任。他知道这场战斗的真正目的不是"赢"，是"封"。他知道妹妹（女主）的封印能力意味着什么。他说话刻薄不是性格差——是没时间解释，也没法解释。他每次看向女主时眼底有一闪而过的痛——他从妹妹十岁起就知道这一天会来。

### 具体造型

- **年龄/面容**：25岁。还没长出"导师"的沉稳，但已经没了年轻人的天真。轮廓分明，眉骨高——看起来很聪明也很多虑。眼角有细纹——不是年龄，是元素力量的后遗症。嘴角常年向下，不是生气，是沉重。
- **发型**：深蓝色短发，略凌乱，左侧有一撮永远翘起的发。女主小时候会伸手帮他按下去，现在没人按了。
- **法袍**：深蓝灰为主，银灰包边，内衬暗金。法袍下摆烧焦、左袖撕裂——都是战斗痕迹。背后的元素三角徽记（火·冰·雷）中，冰的那角已有裂纹——不是巧合，是他最擅长冰系，也是他消耗最大的那部分力量。
- **法杖**：单手杖约1.2m。暗色古木杖身，天蓝色水晶嵌在顶端，三颗小元素珠（红火·蓝冰·黄雷）环绕悬浮。施法时对应珠子亮起。
- **体态**：偏瘦，持杖像握工具。站桩输出的时候手指精准而克制，不多余一个动作。但偶尔会有下意识的小动作——拇指摩挲杖身，是他在想事情。

### 色彩方案
- 法袍：深蓝灰(#384860) + 银灰(#90a0b0) + 暗金内衬(#706030)
- 法杖：暗木(#3a2820) + 天蓝水晶(#60a0d8) + 元素珠红(#d84030)/蓝(#4080d0)/黄(#d8b030)
- 面容：偏冷白(#d8d0d0)，眼下暗色(#605860)

### 情绪关键词
天才会用的最笨的温柔·提前十年开始悲伤的人·用行动说没说出口的话


## 五、女主（17岁）

### 核心意象
**「她不是在牺牲——她早就在等这一刻。只是没想到是现在。」**

17岁。从记事起就知道自己体内住着"可以用来封印黑暗神的东西"。她的沉默不是内向——是用沉默消化了十几年。她看黑暗神时看到的不是怪物，是那个黑影里的少女——和她一样银白色长发的女孩。那是她的倒影，她的未来。

### 具体造型

- **年龄/面容**：17岁。面容柔和，但不柔弱。眉毛细而平直，嘴唇常抿着。眼角微垂——不是悲伤，是"早早接受了命运"的平静。第一章里她对醒来的主角说的第一句话是：「你醒了。」——两个字，承载了整个序章的重量。
- **眼睛**：浅琥珀色——全篇最重要的视觉细节。比常人稍亮，因体内承载了太多记忆。封印发动时瞳孔边缘出现暗紫纹路，从边缘向内蔓延，像冰裂。牺牲前的最后一帧，双目变成纯金色——然后人消失，只剩光点。
- **发型**：银白色长发（封印能力的代价，和黑影中的少女同色），到腰。深蓝发绳简单束在身后——这是大法师给她系的，和她小时候一样。刘海向右侧分，露出左眼——左眼是封印纹路最先出现的位置。
- **服装**：白色多层长袍。外层半透白纱，内层象牙白棉麻。领口浅金锁边。深蓝色腰带——和大法师的法袍同色，是他送的。右手腕一把简单银手镯——前世英雄年轻时送她的护身符，她从来没有摘下来过。第一章女主同样戴着它，是观众认出她的第一个线索。
- **体态与动作**：身高中等，体态轻盈。不施法时双手交握在身前——不是拘谨，是她从小养成的习惯。施法动作极轻：守护之盾是单手向前推掌，弱点标记是指尖轻点。没有夸张的pose。
- **封印纹路（全片核心画面）**：暗紫色，从胸口→锁骨→颈侧→左眼，形态像冰裂纹或枯枝，不对称。发动时纹路从紫色烧成金色——不是渐变色，是像火焰蔓延。注意：纹路的蔓延方向和黑影中少女身上的纹路完全一致。她们是镜像。

### 色彩方案
- 服装：象牙白(#f0e8d8) + 半透白纱 + 浅金锁边(#c8b078)
- 头发：银白(#e8e0d8)，光下微泛蓝(#d8e0f0)——和黑影少女同色
- 眼睛：琥珀(#c89850) → 封印时紫边(#7040c0) → 牺牲时纯金(#ffd040)
- 配饰：深蓝腰带(#384860) · 银手镯(#c0c0c0)
- 封印纹路：暗紫(#6030b0) → 燃为金(#e0a020→#ffe8a0)

### 情绪关键词
沉默但每个眼神都有分量·提前接受了命运·记住一切的人

## 六、核心视觉呼应（暗线）

### 女主 ↔ 黑影少女
- 同样银白长发
- 同样15-18岁的年纪
- 封印纹路蔓延方向完全一致
- 一个在外面准备封印，一个已经在里面被同化
- **全篇最深的画面**：女主抬头看黑暗神的瞬间——她透过黑影看到了那个女孩，那个女孩闭着眼。她们隔着暗影，面对面。一个走向终点，一个已经是终点。

### 前世英雄 ↔ 第一章主角
- 23岁 vs 18岁，同名同姓
- 左鬓同一位置的白发
- 同一个银手镯（前世英雄送的 → 主角第一次见女主时，会看到那个手镯）

### 大法师 ↔ 女主
- 法袍同色的腰带——他给她的
- 他从女主十岁起就知道她的命运
- 全场最痛的一句台词不是女主的遗言，是大法师在她消失后接住光点时——什么都没说


## 七、三人站位关系

### 开场冲击波后
```
        黑暗神 ← 黑影中有少女轮廓
              ↓ 冲击波
    英雄 ←←←←④→→→→ 女主
    （飞出8m）         （只退了半步——她在看黑影里的少女）
            大法师
           （退三步，在看女主）
```
- 女主看黑暗神（看的是黑影里那个和自己一样的女孩）
- 大法师看女主（他知道她在想什么）
- 英雄在看剑（他在算还能打几个回合）

### 封印发动
```
    英雄（左·跪地）   大法师（右·伸手想拉她）
              ↖    ↗
              女主
          （正中·金光照耀）
           她最后看了一眼黑影中的少女
           少女睁开了空洞的眼眶
```
- 黑影少女睁眼只有一秒——女主看到了，观众也看到了
- 然后女主闭上眼
- 黑影少女也重新闭眼

## 八、第1集完整节拍表（v1.2）

> 新增 Beat -1：开场打斗展示圣骑士魅力与黑暗神异常抗性

### Beat -1 — 开场：无效的圣光（新增）

| 属性 | 内容 |
|------|------|
| **时间** | 0s – 8s |
| **核心目的** | 展示前世英雄有多强 + 黑暗神有多不可战胜 |

| 秒 | 画面 | 情绪 |
|----|------|------|
| 0–1 | **黑屏**。一声剑鸣——金属在空气中高速划过的尖锐音。画面骤然亮起。前世英雄已经在空中——他跳起来的高度不自然，背后炸开一对半透明的金色光翼残影（圣光蓄能·光之解放的余效）。他双手握剑过头，剑身燃烧着炽白金色火焰。整个画面以他为光源——战场第一次被照亮。 | 开场即巅峰——这个男人不是来试探的，他是来终结的 |
| 1–2 | **斩击命中**。剑劈在黑暗神左肩的黑影上。金色光爆炸开，冲击波以接触点为中心向外扩散——地面焦土被掀起，碎石在金光中化为流影。英雄的力量是真实的，这一剑的视觉冲击力必须让观众觉得"这下应该结束了吧"。 | 观众的预期：一剑定胜负 |
| 2–3 | **黑暗神没有反应**。光爆消散。黑暗神的黑影左肩处——那个被劈中的位置——黑影短暂裂开了一道口子，能隐约看到里面的少女轮廓。但仅仅半秒，黑影就愈合了。没有惨叫，没有后退，没有硬直。黑暗神甚至没有低头看英雄——它的视线不在他身上。 | 观众的预期被打破——这么强的一击，对方连看都不看 |
| 3–4 | **英雄的连击**。他不信。落地瞬间左脚蹬地，身体旋转——辉光斩，120°扇形横斩，混合神圣伤害全开。然后是盾击——盾面砸进黑影，眩晕判定。然后是冲锋——直线冲刺穿透黑影躯体，圣光在路径上留下灼痕。三连击在一秒内打完。每一下都命中。每一下都毫无用处。 | 他在用全力验证一个他不愿相信的事实 |
| 4–5 | **黑暗神胸口的少女**。在英雄冲锋穿透的瞬间，圣光短暂照亮了黑影内部——观众第一次看清那个少女的轮廓。银白色长发，闭眼，悬浮。她的表情太平静了，和外部正在发生的战斗完全不在同一个频道。英雄自己也看到了——他穿透黑影时离少女只有几米。他的表情变了：不是恐惧，是"原来如此"的领悟。 | 观众第一次看到黑影中的少女——安静得可怕 |
| 5–6 | **黑暗神的反应——一次就够了**。它终于"低头"了。黑影缓慢地向英雄的方向倾斜——不是快速的攻击，而是像一个人终于注意到脚边有只蚂蚁。黑暗神抬起一条手臂——暗影凝聚成巨大的鞭状，从英雄头顶砸下。英雄举剑格挡。剑上的金色光流在接触暗影的瞬间剧烈闪烁——像蜡烛被风吹。 | 黑暗神的"攻击"不是愤怒——是漫不经心 |
| 6–7 | **格挡破碎**。剑上的金光灭了。英雄被砸进焦土——整个人嵌进地面，周围裂开蛛网状的缝隙。他的剑插在3米外的土里，剑身仍在微微发光——剑还在战斗，但他已经站不起来了。倒地时他吐出一口血，视线模糊。从第一人称视角看——黑暗神巨大的黑影充满了整个视野，模糊边缘中，少女的轮廓若隐若现。 | 圣骑士的极限到了。不是他弱——是对手不在同一个维度 |
| 7–8 | **黑暗神不再看他**。它重新抬起头，黑影恢复到之前的姿态。它没有补刀，没有嘲讽——它只是不再觉得英雄值得关注。英雄的手在焦土上握拳，指尖抠进裂缝。他的眼神不是绝望——是不甘心。远处传来大法师的声音：「——」声音被冲击波打断。（接 Beat 0） | 愤怒来自无能。不是英雄的愤怒——是观众的愤怒。这为女主的牺牲埋下情绪基础 |

### 这个开场确立了：
