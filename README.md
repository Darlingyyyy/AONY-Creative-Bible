# AONY Creative Bible

> 即使整个世界忘记了你，我也会再次找到你。

AONY 是一个围绕「记忆与重逢」展开的幻想动画 / RPG IP。这个仓库专门用于沉淀 **剧情、人物、视觉设定、动画脚本、镜头拆解与出图提示词**。

## 当前定位

本仓库不是游戏工程仓库，也不是素材大仓库。  
它是 AONY 的创作中枢，用来回答：

- 故事讲什么？
- 角色是谁？
- 第一集怎么拍？
- 视觉风格如何保持一致？
- 下一批关键帧和发布内容怎么推进？

## 当前制作优先级

1. 锁定第一批视觉草案：塞莉亚、艾伦今生、EP01-KF05。
2. 以 EP01《前世梦境》为第一条可发布动态分镜样片。
3. 继续扩展 EP01 8 张关键帧。
4. 后续单独重做全员脸部设定，避免网红脸、模板脸、偶像脸。
5. 在 EP01 样片稳定后，再决定是否回流游戏原型。

## 与 Project-Astra 的关系

`Project-Astra` 是 AONY 的早期游戏设计仓库，偏 Unity、战斗系统、职业技能树和关卡原型。

本仓库则是 AONY 的创作向仓库，优先服务剧情、人物、动画场景和视觉资产生产。后续如果重新启动游戏原型，可以从这里回流最新的故事和角色设定。
