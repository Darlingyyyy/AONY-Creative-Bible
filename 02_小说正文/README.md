# Project Astra · 轻小说

> 动画的前置工程。先写完完整小说，再拆成动画脚本。

## 目录结构

```
novel/
├── README.md              ← 本文件
├── outline.md             ← 全篇大纲（各章节概要）
├── characters.md          ← 角色设定（直接从 outputs 复制）
├── ch01-prologue.md       ← 序章：前世梦境
├── ch02-awakening.md      ← 第一章：成人仪式
├── ch03-xxx.md            ← 第二章（待定）
├── ...
└── notes/                 ← 创作笔记、灵感、废弃片段
```

## 写作原则

1. **情感驱动**：每章必须服务于「记忆与重逢」
2. **女主沉默有意义**：不随便让她说话
3. **伙伴不是工具人**：每个有独立弧线
4. **先写完再改**：不追求初稿完美
